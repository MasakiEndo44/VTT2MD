# 議事録用フィラー・相槌自動削除リスト

## 基本フィラー（必須削除）

### 代表的なフィラー
- えー、えーと、えっと
- あー、あのー、あの
- その、そのー、その何
- まあ、まぁ
- なんか、何か
- ちょっと（意味のない場合のみ）

### 音引き表現
- そうですねー、はいー
- でー、じゃー、それでー
- というかー、まあー

## 相槌・同意表現（文脈判断型削除）

### 純粋な相槌（削除対象）
- はい、はいはい、はいはいはい
- そうですね、そうそう、そう
- なるほど、なるほどね
- うん、うんうん
- ええ、ええそうです
- そうですそうです

### 意味を持つ同意（保持対象）
- はい、承知いたします
- そうですね、○○の件については
- なるほど、それでは○○を
- ええ、その通りだと思います

## 間投詞・つなぎ語

### 削除対象
- うーん、んー、ふーん
- へー、ほー、はー
- まあそうですね
- そうですねえ
- どうでしょうね
- なんでしょうね

### 語頭の無意味な接続
- で、まあ～
- それで、あの～
- じゃあ、その～
- あと、えー～

## 言い直し・訂正パターン

### 自己訂正表現
- いや、そうじゃなくて
- あ、違います、○○です
- じゃなくて、○○ですね
- というか、○○の方が
- 正確には、○○ですが

### 繰り返し表現
- ○○、○○です（同一語句の無意味な重複）
- というのは、というのは
- ですから、ですから
- そうです、そうです

## 時間稼ぎフレーズ

### 思考時間稼ぎ
- そうですね、どう言ったらいいでしょう
- なんて言うんでしょうか
- どういう風に説明しようかな
- うーん、どうしましょう
- ちょっと待ってください（考え中）

### 発言開始時の無意味なフレーズ
- じゃあ、まず最初に
- そうですね、まあ
- えーと、そうですね
- あのですね、まず

## 語尾のフィラー

### 文末の無意味な付加
- ～ですけどね
- ～なんですがね
- ～っていうかね
- ～みたいなね
- ～なんかね
- ～とかね

## 削除時の注意事項

### 保持すべき表現（削除禁止）

#### 意味のある「ちょっと」
- ちょっと待ってください（依頼）
- ちょっと違うと思います（否定）
- ちょっと難しいですね（評価）

#### 意味のある「まあ」
- まあ、問題ないでしょう（評価）
- まあまあの出来ですね（程度表現）

#### 重要な接続詞
- それで、結論としては（論理的接続）
- じゃあ、次に移りましょう（進行）
- あと、重要なポイントが（追加）

## 削除アルゴリズムの優先順位

### Level 1：無条件削除
文頭・文中の単独フィラー（えー、あのー、その など）

### Level 2：文脈判断削除
相槌や同意表現（後に具体的内容が続かない場合）

### Level 3：繰り返し削除
同一語句・フレーズの無意味な重複

### Level 4：構造的削除
言い直し・訂正時の冗長な表現部分

## 実装時の処理ルール

```markdown
削除処理の基本パターン：

1. 文頭フィラー削除：「えー、○○です」→「○○です」
2. 文中フィラー削除：「○○は、あのー、△△です」→「○○は△△です」
3. 重複削除：「はい、はい、承知しました」→「はい、承知しました」
4. 無意味相槌削除：「A：○○ですか？ B：そうですね。」→削除または「承知しました」に変換
5. 言い直し整理：「いや、そうじゃなくて○○です」→「○○です」
```

## 品質保証チェック

削除後に以下を確認：
- 文意の変化がないか
- 重要な情報が失われていないか  
- 自然な日本語として成立しているか
- 発言者の意図が正確に伝わるか
