# VTT to MD 変換ツール 要件定義書

## 1. 概要

### 1.1 目的
Microsoft Teams会議のトランスクリプト（VTTファイル）を、Copilotで処理しやすい整形されたMarkdown形式に自動変換するデスクトップアプリケーションを開発する。

### 1.2 背景
- Copilotは直接VTTファイルを読み込めない
- 手動での整形作業は時間がかかる
- 議事録作成の効率化が必要

### 1.3 スコープ
- **含む**: VTTファイルの読み込み、話者情報の抽出、発言の結合、軽量なフィラー除去、MD形式での出力、出力ファイルの分割
- **含まない**: 高度な自然言語処理に基づく発言内容の修正（誤字脱字、表記ゆれ訂正）

## 2. 機能要件

### 2.1 ファイル入力機能
- ドラッグ&ドロップによるVTTファイル入力
- ファイル選択ダイアログによる入力（代替手段）
- VTTファイル以外の拒否とエラー表示
- **会議日時（日付と開始時刻）の手動入力機能（カレンダーUIによる日付選択を含む）**

### 2.2 データ解析機能
- VTTファイルからの話者名抽出
- 発言時刻と内容の抽出
- 会議名のファイル名からの抽出（拡張子を除く）
- 入力された会議日時（日付と時刻）の保持

### 2.3 データ変換機能
- 同一話者の1分以内の連続発言を結合
- 時刻フォーマットの変換（HH:MM:SS → [HH:MM:SS]形式）
- 話者一覧の自動生成
- 所要時間の自動計算

### 2.4 出力機能
- Markdown形式でのテキスト生成
- ヘッダー情報として会議名と、手入力された会議日時を記載
- 変換結果のプレビュー表示
- ファイルダウンロード機能
- **出力ファイルの分割機能:**
  - ユーザーは「単一ファイル」か「複数ファイル（1ファイル10000文字以下）」かを選択できる。
  - **分割を選択した場合、保存ダイアログで指定した名前で新しいフォルダが作成され、その中に連番のファイルが保存される。** (例: `MyMeeting`フォルダ内に`MyMeeting_part1.md`...)
  - 分割時、ヘッダー情報（会議名、日時など）はすべてのファイルに共通して記載される。
  - 発言の途中で文章が分割されないように、発言単位で分割処理を行う。

### 2.5 エラーハンドリング
- 不正なファイル形式の検知と通知
- 変換エラーの適切な表示
- ユーザーへの分かりやすいエラーメッセージ

### 2.6 軽量フィラー自動除去機能
- 文字起こしに含まれる無意味なフィラーや相槌を、辞書ベースの単純な文字列置換によって自動で除去し、可読性を向上させる。
- 除去対象の単語やルールは、別途定義する `docs/filler_deletion_list.md` を参照する。
- **高度な除去ルール:**
  - `うんうんうん`のような同一相槌の3回以上の繰り返しも除去する。
  - フィラー除去の結果、`、`や`。`などの句読点のみが残った場合は、その発言自体を空にする。
- ユーザーが機能の有効/無効を選択できるよう、GUIにON/OFFトグルスイッチを設ける。

## 3. 非機能要件

### 3.1 ユーザビリティ
- 直感的で分かりやすいUI
- MS LoopやClaude Desktopに近い操作感
- 白基調のモダンでスタイリッシュなデザイン

## 3.2 パフォーマンス
- アプリケーションの起動時間は10秒以内とする。
- 1時間程度の会議録（約10MB）を5秒以内に変換。

### 3.3 互換性
- Windows 11での動作
- UTF-8エンコーディング対応

### 3.4 容量・依存関係
- 実行ファイルに含める追加ライブラリは最小限に留め、軽量な配布物とする。

## 5. データフロー

```mermaid
graph LR
    A[VTTファイル] --> B[ファイル読み込み/日時入力]
    B --> C[データ解析]

    D --> E[発言結合処理]
    E --> F[軽量フィラー除去処理]
```

## 6. 技術仕様

### 6.1 開発環境
- 言語: Python 3.9以上
- GUI: Tkinter (+ ttk)
- 追加ライブラリ: 
  - `webvtt-py`（VTT解析）
  - `datetime`（時刻処理）
  - `pathlib`（ファイル操作）
  - `tkcalendar`（カレンダーUI）

### 6.2 ファイル形式
- 入力: WebVTT形式（.vtt）
- 出力: Markdown形式（.md）
- 文字コード: UTF-8

## 7. 制約事項

- Windows 11環境でのみ動作保証
- オフライン環境で動作

## 8. 今後の拡張性

- 複数ファイルの一括処理
- 他の字幕形式（SRT等）への対応
- 発言内容のフィルタリング機能
- エクスポート形式の追加（DOCX、PDF等）
