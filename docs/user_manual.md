# VTT2MD ユーザーマニュアル：Teams会議からCopilot議事録作成まで

## 1. はじめに

このマニュアルは、Microsoft Teamsの会議の文字起こし（VTTファイル）を `VTT2MD` アプリケーションを使って整形し、最終的にCopilotで高品質な議事録を効率的に作成するまでの一連の手順を解説します。

## 2. 全体の流れ

作業は大きく分けて3つのステップで完了します。

1.  **【Teams】** 会議の文字起こし（VTTファイル）をダウンロードする
2.  **【VTT2MD】** VTTファイルを議事録のもとになるMarkdownファイルに変換する
3.  **【Copilot】** 変換したMarkdownファイルを使って、議事録を生成する

---

## 3. ステップ1：TeamsからVTTファイルをダウンロードする

まず、議事録を作成したいTeams会議から、文字起こしデータ（トランスクリプト）をダウンロードします。

1.  会議が終了すると、Teamsのチャット欄やカレンダーの会議イベント詳細に、会議の録画（レコーディング）が表示されます。
2.  その録画をクリックして開きます。
3.  ビデオプレーヤーの右上にある「レコーディングとトランスクリプト」パネルを開きます。
4.  「トランスクリプト」タブを選択し、言語が正しく設定されていることを確認します。
5.  ダウンロードボタン（↓のアイコン）をクリックし、**「.vtt形式でダウンロード」** を選択します。

これで、お使いのPCの「ダウンロード」フォルダなどに `.vtt` ファイルが保存されます。

> **💡ヒント:** ファイル名は通常 `Meeting_YYYY-MM-DD_HH-MM-SS-transcript.vtt` のようになります。

---

## 4. ステップ2：VTT2MDでMarkdownファイルに変換する

次に、ダウンロードしたVTTファイルを `VTT2MD` アプリケーションで読みやすく、AIが処理しやすいMarkdown形式に変換します。

1.  `VTT2MD.exe` をダブルクリックしてアプリケーションを起動します。

2.  ウィンドウが表示されたら、先ほどダウンロードした `.vtt` ファイルを**ウィンドウ内にドラッグ＆ドロップ**します。
    （または、「ファイルを選択して変換開始」ボタンからファイルを選ぶこともできます）

3.  **「会議の日時を入力」** ダイアログが表示されます。会議が開始された正確な **日付** と **時刻（24時間表記）** を入力し、「OK」をクリックします。これは、議事録に正確なタイムスタンプを記載するために重要です。

4.  **オプションを選択します。**
    -   **フィラー・相槌を除去する:** 「えーと」「あのー」のような不要な言葉を自動で取り除き、文章をスッキリさせます。（推奨：ON）
    -   **出力形式:** 長い会議の場合、Copilotが一度に処理できる文字数に合わせてファイルを分割できます。（通常は「単一ファイル」で問題ありません）

5.  変換が完了すると、結果がプレビュー表示されます。

6.  **「💾 ダウンロード」** ボタンをクリックし、分かりやすい名前を付けて `.md` ファイルを保存します。

---

## 5. ステップ3：Copilotで議事録を作成する

最後に、変換して保存したMarkdownファイルを使って、Copilotに議事録を作成してもらいます。

1.  保存した `.md` ファイルをメモ帳などのテキストエディタで開きます。

2.  ファイルの内容をすべて選択し、コピーします。（`Ctrl + A` → `Ctrl + C`）

3.  お使いのCopilot（Copilot for Microsoft 365など）を開き、チャット入力欄に、まず**やってほしいこと（プロンプト）**を入力します。

4.  プロンプトに続けて、先ほどコピーしたMarkdownの内容を貼り付けます。（`Ctrl + V`）

5.  送信ボタンを押して、Copilotからの応答を待ちます。

### ✨ Copilotへの指示（プロンプト）の例

以下に、コピー＆ペーストして使えるプロンプトの例をいくつか紹介します。目的に合わせて使ってみてください。

**例1：要約とToDoリストの作成**
```
以下の会議の文字起こしを要約し、主要な決定事項と、誰が何をするべきかのアクションアイテム（ToDo）をリスト形式で抽出してください。

（ここにMarkdownの内容を貼り付け）
```

**例2：トピックごとの議論まとめ**
```
このトランスクリプトを基に、議論されたトピックを特定し、それぞれのトピックごとに議論の概要をまとめてください。

（ここにMarkdownの内容を貼り付け）
```

**例3：フォーマルな議事録の清書**
```
以下の文字起こしから、フォーマルな議事録を作成してください。以下の項目を必ず含めてください。

- 会議名
- 日時
- 出席者
- 議題
- 議論内容
- 決定事項
- ネクストステップ（担当者と期限も記載）

（ここにMarkdownの内容を貼り付け）
```

以上で、議事録作成は完了です。Copilotが生成した内容を確認し、必要に応じて手直ししてください。
